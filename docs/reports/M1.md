# M1 — задачи и планировщик
Реализованы CRUD задач/проектов, мягкое удаление/архивация, undo, недельный backlog без дня, назначение даты/времени, три вида задач, drag-and-drop Kanban и календаря, предупреждение пересечений. История в change_log. Изменение даты не создаёт новые ID.

Проверки: 4/4 unit/integration (Foundation, сохранение/перезапуск SQLite, snapshot, undo, пересечения, границы распределения). Typecheck/build прошли. E2E UI — отдельный JSON-отчёт. Скриншот M1.png.

Частично: расширенные фильтры, иерархия подзадач, массовое изменение, повторы/occurrences, attachments, milestone roadmap, resize календаря ещё не реализованы. Это MVP, не полный M1+релиз.

Windows: README — `pnpm install; pnpm rebuild; pnpm dev`. Проверено в Linux Electron; Windows не подтверждён.
