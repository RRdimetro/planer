# FOCUS OS PRO — Forest Noir V4, Gate B

Дата: 3 ноября 2026. Ветка: `design/forest-noir-v4`. Это три реализованных направления главной страницы, а не утверждённый редизайн всего приложения.

| Концепция                  | Композиция и характер                                                                                                  | Когда выбирать                                                    | Компромисс                                                              |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- | ----------------------------------------------------------------------- |
| A. Editorial Forest        | Локальная панорама, Lora для крупной типографики, редакционные списки с тонкими разделителями, спокойный темп чтения   | Если главное — атмосфера и выразительность                        | Больший акцент на вступлении, часть рабочих блоков ниже первого экрана  |
| B. Obsidian Command Center | Узкая панель навигации, информационная полоса дня, три рабочие колонки, видимый таймер и расписание                    | Если важнее быстро управлять насыщенным днём                      | Меньше природной атмосферы, выше информационная плотность               |
| C. Atmospheric Bento       | Асимметричные 5/4/3 и 7/5 блоки, пейзаж внутри одного блока, мягкие нейтральные градиенты, видимые приоритеты и неделя | Если нужен баланс эстетики, контекста и ежедневного использования | Карточная структура; при большом количестве задач потребуется прокрутка |

**Рекомендация: C.** На первом экране вместе читаются результат недели, сегодняшние задачи и календарный контекст. Пейзаж поддерживает один блок и не вытесняет рабочее содержимое. B предпочтительнее для максимально плотного управления; A — для более редакционной, спокойной подачи. Направление пока не выбрано.

## Реальные скриншоты

`docs/screenshots/forest-noir-v4/` содержит 12 основных PNG: A/B/C × populated/empty × 1920×1080/1366×768. Размер PNG соответствует области приложения, а не уменьшенному макету. `before/` — два исходных снимка. `details/` — боковые панели и палитра команд. `regression/` — девять неизменённых страниц в двух режимах для визуального сравнения.

`docs/motion/forest-noir-v4/C-interactions.mp4` — запись настоящего Electron: завершение/отмена задачи, боковая панель, команды, навигация, перетаскивание события в существующем календаре, запуск/пауза/завершение фокуса. Запись 25 кадров/с не является замером производительности 60fps.

## Что работает в каждом варианте

- Создание, редактирование, завершение, возврат и отмена изменения задачи; существующие чек-листы и связи доступны в боковой панели шириной 480px.
- Фильтры сегодняшних задач, переходы к проектам, учёбе, тренировкам и планировщику; все 10 существующих страниц доступны.
- Фокус с реальной сессией SQLite: запуск, пауза, продолжение, завершение, сохранённое время.
- Недельный график с переключением задач/минут фокуса, значения по дням при наведении или выборе клавиатурой; нулевые значения не заменяются активностью.
- Эффективность из существующей аналитики: сравнение с прошлой неделей, число известных компонентов, раскрываемое определение. Пустая оценка — «—».
- Проектный прогресс, ближайшие сроки, расписание, недельные факты тренировок, учебные агрегаты из текущих записей.
- Палитра команд на главной: Ctrl+K, нечёткий поиск, стрелки, Enter, Escape; Ctrl+N создаёт задачу. Поиск предмета открывает учебный трекер; выбор конкретной ячейки пока не реализован.
- «Без пейзажа» отключает сцену; reduced motion отключает переходы. Декоративных сетевых запросов нет.

## Изоляция данных

Для A/B/C созданы разные каталоги SQLite; у пустых состояний ещё три отдельных каталога. Launcher очищает `FOCUS_DATA_DIR`, чтобы не унаследовать путь к рабочей базе. Дополнительный marker не позволяет открыть существующий немаркированный файл как preview или переиспользовать каталог другой концепции. Повторный запуск сохраняет сделанные изменения. Схема SQLite по-прежнему v3; новых миграций нет.

Во всех заполненных демо сохранены исходные 9 предметов, 4 группы и 54 статуса. Неизвестное не превращается в «не выполнено», подробные этапы не складываются повторно с агрегатами. Демо-показатели явно помечены и не выдаются за пользовательские данные.

## Компоненты и токены

Добавлены ForestHome, ForestPalette, ограниченные preview-областью Panel/Empty, стили боковой панели, авторский SVG valley, локальные Manrope/Lora с OFL-лицензиями. Существующий ItemForm и IPC используются повторно. Magic UI изучен как источник подходов; сторонние компоненты в приложение не скопированы.

Токены из brief находятся в начале `apps/desktop/src/pages/forest-v4/forest-noir.css`. Они ограничены preview главной и её диалогами: canvas #080E0B, sidebar #0C1510, три нейтральных surface, accent #73D99B, primary text #F1F7F2, semantic warning/info/danger, радиусы 8/12/18px. Это проект основы, не глобальная смена темы остальных страниц.

## Проверки и границы

- TypeScript strict, ESLint, production build и 38 unit/integration тестов прошли.
- Electron/Linux: 12 основных скриншотов, пустые действия, task CRUD/undo, фокус, поиск, keyboard shortcuts, 10 маршрутов, offline-работа и сохранение после настоящего перезапуска всех шести preview-баз.
- Визуальная регрессия девяти остальных страниц: 0 изменённых пикселей на контрольных снимках 1366×768.
- Проверка Home A при 1366×768, 1440×900, 1920×1080, 2560×1440 с zoom 100/125/150%: без горизонтального переполнения. Основные A/B/C проверены в обоих запрошенных разрешениях. Zoom Linux Chromium не подтверждает Windows DPI.
- Изоляция: пользовательская SQLite остаётся побайтно неизменной при создании и редактировании трёх демо-баз; сохранение учебных правок после повторного открытия проверено.
- Windows portable preview собран cross-build и помечается UNTESTED. Реальные Windows 10/11, Windows CI, установка/обновление и 60fps на Windows в этой среде не проверялись. Git remote не настроен; Windows executor отсутствует.
- Полный аудит доступности, всех Windows DPI/системных шрифтов и производительности не объявляется выполненным. Остаются предупреждения Vite о размере JS chunk и аннотациях зависимости Zod.
- Настройка/перестановка старых виджетов сохраняется в классической Home. В новых концепциях композиции фиксированы для сравнения; сохранённые настройки старой Home не удаляются.
- Переход с команд на конкретную заметку/ячейку учёбы, перенос единой новой палитры и темы на остальные страницы — после выбора направления.

Отчёты: `dashboard-e2e.json`, `visual-regression.json`, `motion.json`, `unit-tests.txt`, `windows-preview.json`. Windows-статус не меняется на успешный от наличия exe.

## Запуск

Для готового Windows preview распакуйте `Windows_Preview_UNTESTED.zip` целиком. Запустите `A_Editorial_Forest.cmd`, `B_Obsidian_Command_Center.cmd` или `C_Atmospheric_Bento.cmd`. Для пустого состояния — соответствующий `A_Empty.cmd`, `B_Empty.cmd`, `C_Empty.cmd`. Не удаляйте каталоги демо, если хотите сохранить свои пробные изменения. Прямой запуск exe открывает классический рабочий режим, поэтому для сравнения используйте CMD-файлы.

Из исходников на Windows 10/11 x64 с Node 22+ и pnpm 10.20.0:

```powershell
pnpm install
pnpm run rebuild
pnpm build
pnpm preview:design A
pnpm preview:design B
pnpm preview:design C
pnpm preview:design C --empty
```

Классический рабочий запуск: `pnpm exec electron .`. Проверки: `pnpm typecheck`, `pnpm lint`, `pnpm test`, `pnpm test:forest`. Визуальный скрипт дополнительно использует Python/Pillow, motion-скрипт — Linux Xorg/ffmpeg; это инструменты доказательной проверки, не зависимости пользовательского Windows-приложения.

После выбора A/B/C можно переходить к следующему этапу. Сейчас редизайн остальных страниц не начинался.
