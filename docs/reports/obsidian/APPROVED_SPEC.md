# FOCUS OS PRO — Obsidian Command Center
## ТЗ для Codex: полная реализация приложения

**Статус:** дизайн главной страницы утверждён.

**Выбранный вариант:** B — Obsidian Command Center.

**Задача:** завершить разработку полноценного локального Windows-приложения FOCUS OS PRO с новым дизайном на всех страницах.

---

## 1. Главное требование

Пользователь выбрал вариант B из трёх предложенных концепций Forest Noir V4.

Этот вариант становится **единственным визуальным эталоном проекта**.

Используй реализованный вариант B непосредственно из текущей кодовой базы. Не пытайся воссоздать его приблизительно по текстовому описанию.

Не изменяй утверждённую главную страницу без объективной необходимости.

Сохрани её:

- Общую композицию.
- Цветовую палитру.
- Типографику.
- Систему карточек.
- Графики.
- Визуальную глубину.
- Анимации.
- Оформление навигации.

Допускаются точечные улучшения читаемости, адаптивности и производительности.

**Не создавай новый дизайн. Развивай утверждённый.**

## 2. Основные требования к приложению

Платформа: Windows 10/11 x64.

Технологии:

- Electron.
- React + TypeScript.
- Tailwind CSS.
- SQLite.
- Motion.
- Recharts.
- Локальное хранение пользовательских данных.

Приложение должно полноценно работать без интернета.

Все данные сохраняются после закрытия и перезапуска.

Не допускается потеря существующих данных при обновлении.

Не переписывай проект с нуля.

## 3. Полная структура приложения

Реализуй и визуально переработай все 10 разделов.

### 01. Главная — Command Center

Сохрани утверждённый вариант B.

Подключи все виджеты к реальным данным.

Обязательные показатели:

- Эффективность за день и неделю.
- Количество выполненных задач.
- Недельный прогресс.
- Ближайшие дедлайны.
- Фокус-время.
- Тренировки.
- Прогресс проектов.
- Расписание на сегодня.
- Динамика продуктивности.
- Быстрые действия.

Добавь настройку расположения виджетов, их видимости и размеров.

### 02. Планировщик — Planner

Это один из главных разделов.

Создай профессиональный календарный интерфейс в стилистике Obsidian Command Center.

Режимы:

- День.
- Неделя.
- Месяц.
- Список событий.

Функции:

- Drag-and-drop задач и событий.
- Изменение длительности блоков.
- Повторяющиеся события.
- Отображение университетских занятий.
- Отображение тренировок.
- Свободные временные интервалы.
- Автоматическое обнаружение конфликтов.
- Создание задач непосредственно из календаря.
- Перемещение задач между днями.
- Панель нераспределённых задач.

Отдельно реализуй интеллектуальное планирование с учётом свободного времени, ограничений и приоритетов.

Автоматические предложения не должны изменять расписание без подтверждения пользователя.

### 03. Задачи — Task Manager

Создай три полноценных режима:

1. Kanban.
2. Таблица.
3. Недельный список.

Обязательный функционал:

- Задачи и подзадачи.

- Категории.

- Дедлайны.

- Чек-листы.
- Вложения.
- Фильтрация.
- Поиск.
- Массовые операции.
- История переносов.

При открытии задачи используй боковую контекстную панель, а не перегруженное модальное окно.

Особенно тщательно реализуй недельный backlog.

### 04. Проекты — Project Hub

Сделай полноценный центр управления проектами.

Функциональность:

- Создание и редактирование проектов.
- Цели проекта.
- Этапы.

- Kanban и Gantt-представления.

Визуально выдели крупные проекты выразительными карточками и графиками.

### 05. Учёба — University Hub

**Критически важно: не потерять данные из оригинального Excel.**

Сохрани девять предметов и все ранее импортированные учебные статусы.

Основная задача страницы — быстро отмечать выполненные работы.

Реализуй:

- Общую сводную таблицу.
- РК написано / всего.
- ДЗ сдано / всего.
- Экзамены.
- Итоговые результаты.
- Отдельные группы лабораторных и домашних заданий.
- Этапы выполнения, сдачи и защиты.
- Три состояния: выполнено, не выполнено, неизвестно.
- Автоматический пересчёт показателей.
- Редактирование групп.
- Добавление новых работ.
- Импорт и экспорт Excel.
- Сохранение после перезапуска.

Не усложняй повседневное отмечание работ.

Пользователь должен менять состояние одной ячейки за один клик.

## 7. Производительность и безопасность

Приложение должно:

- Быстро запускаться.
- Не зависать при работе с календарём.
- Корректно отображать большие списки задач.
- Не терять изменения.
- Сохранять данные при закрытии.
- Корректно обрабатывать ошибки SQLite.
- Использовать безопасный IPC.
- Проверять входящие данные.
- Не обращаться к интернету без необходимости.

Для больших таблиц используй виртуализацию.

Для тяжёлых аналитических расчётов — кэширование и оптимизированные запросы.

## 9. Этапы разработки

Работай последовательно.

Зафиксируй утверждённый вариант B. Вынеси визуальные компоненты, токены и анимации в общую библиотеку.

**Этап B — Core Experience**

Доработай главную страницу, задачи и планировщик.

Полностью реализуй проекты и учёбу.

**Этап D — Lifestyle & Knowledge**

**Этап E — Analytics**

Настройки, резервные копии, Windows-тесты, оптимизация, установщик.

- Запускай тесты.
- Проверяй сохранность данных.
- Делай скриншоты.
- Обновляй IMPLEMENTATION_STATUS.md.
- Фиксируй незавершённые функции.

Не жертвуй качеством реализации ради быстрого закрытия этапов.
