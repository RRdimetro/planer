# M4
Вычисляемая аналитика 7/30/90/произвольный диапазон, графики выполнений и фокуса, heatmap, учебные этапы, компоненты Efficiency Score с исключением отсутствующих наблюдений. Исходные планы — неизменяемые snapshots ID/весов/оценок/сроков. Завершения дополнительно фиксируются историческими фактами, чтобы позднее изменение дедлайна не меняло своевременность прошлого.

Детерминированное распределение: приоритет, дедлайн, свободные интервалы, дневная ёмкость. Предпросмотр и подтверждение. Нет внешнего AI API.
Проверки: автоматические контрольные наборы (пустая БД, перенормировка, 75% взвешенного исходного плана, день отдыха, занятые интервалы, недостаточная ёмкость). Результаты — полный test run. Скриншот M4.png / 07-1366.png.

Частично: нет полного отчёта по переносам, нагрузки по неделям, распределения времени проектов; нет произвольных правил сложных задач после тренировок, гибкой работы на лекциях и зависимостей при smart planning. План применяется последовательными сохранениями, не единой транзакцией.
Windows: команды README; Windows smoke test не выполнен.
