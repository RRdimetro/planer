# F — Desktop candidate 0.3.0

Код этапа реализован и проверен на Linux/Electron. **Приёмка Windows остаётся незавершённой.** Исполнение Windows, установка/обновление, DPI и OS-доставка уведомлений здесь не выполнялись: нет Windows executor, git remote и настроенной авторизации CI.

## Реализовано

- Control Panel: Obsidian, масштаб, плотность, уменьшение движения, timezone, веса, планирование, уведомления, копии/хранение, integrity/FK, demo и версия.
- Автоматические ZIP: проверка checksum и пробного восстановления до атомарной замены/ротации. Настраиваемые часы/retention; ручные и pre-migration файлы сохраняются. Проверенная копия до JSON/XLSX import и ZIP restore.
- Single-instance lock до открытия SQLite, отдельные user/demo каталоги.
- Монотонный timer: сворачивание и busy main учитываются; powerMonitor suspend/resume исключает сон. Undo стороннего действия сохраняет текущие секунды/состояние сессии.
- Локальные напоминания задач/дедлайнов/тренировок/фокуса и сохранённые receipts против повторных запросов. Проверен запрос notification API, не фактическая доставка Windows.
- Измеряемая виртуализация переменной высоты в таблице и Kanban, lazy-loading страниц, кэш аналитики/агрегации переносов.
- Новые строки общего журнала — compact delta-v1; старые строки остаются нетронутыми. Полные entity revisions и ZIP-history сохранены, undo добавляет свою запись и не стирает предыдущие версии. Создание/отмена сущностей использует скрытие, сохраняя идентичность и аудит.
- Календарь 00–24; interval/until в UI серий. Привязанные учебные агрегаты имеют понятный read-only режим.
- Общая библиотека содержит все 19 типов компонентов из ТЗ; реальные TaskCard/ProjectCard/WorkoutCard/Timeline/CalendarEvent встроены в страницы. Эталонная Home B сохранена, A/C не являются актуальными режимами.

## Windows gate и запуск

Кросс-сборка NSIS/portable и статический PE/ASAR/native контроль описываются отдельно в `windows-build.json`. Файл с `_UNTESTED` не становится проверенным Windows-релизом после успешной упаковки. Бинарники unsigned.

Windows source: Node 22+, pnpm 10.20; `pnpm install --frozen-lockfile`, `pnpm run rebuild`, `pnpm build`, `pnpm dev`. Установщик: `pnpm dist:win`. Данные: `%APPDATA%\FOCUS OS PRO`. Полная инструкция — корневой README.

Подготовленный Windows CI реально устанавливает baseline 0.1.0 и обновляет его до 0.3.0 после запуска в доступном репозитории. Его результат сейчас отсутствует; `windows-status.json` остаётся false. Для воспроизведения baseline поставляется полная git-история.

## Не закрытые границы

Windows runtime/install/update/OS notification delivery, подпись и ручной Windows 10/11 usability/DPI. Исторические сессии относятся к дню начала; неизвестные интервалы полуночи/DST не реконструируются. XLSX — шаблон приложения; произвольные XLS не заявляются. Серии ограничены 2–104 встречами. Уведомления требуют запущенного процесса. Пределы backup/вложений и формулы приведены в README. Никакая из этих границ не помечена пройденной.
