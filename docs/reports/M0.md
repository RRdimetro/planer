# M0
Реализованы Electron scaffold, 10 маршрутов навигации, Premium Forest tokens, SQLite WAL, Drizzle repository, транзакционная миграция, Zod IPC и sandbox preload. Node-доступ renderer выключен.

Проверки: Vitest foundation 1/1; typecheck, lint и production build прошли. Проверка GUI в процессе. Windows: команды README, `pnpm install`, `pnpm rebuild`, `pnpm dev`. Windows smoke test в Linux не выполнялся.

Схема использует документированные JSON payload в SQLite records вместо полной нормализации предложенных таблиц. Подробная валидация домена — Zod; это архитектурное отклонение от рекомендованной схемы.
