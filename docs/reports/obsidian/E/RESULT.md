# E — Insights

53 unit/integration + strict TS/lint/build прошли. Electron проверил настоящие графики, фильтры проекта/категории и периода, семь дат heatmap, обработку недопустимого диапазона и отсутствие мутаций БД при просмотре. 4 PNG demo/empty × 1366/1920.

Daily/Weekly Efficiency, взвешенный план, сроки, оценка/факт, рабочее время, переносы, просрочка, нагрузка, weekdays, проекты и fitness выводятся из фактических записей. Сравнение — с предыдущим непересекающимся периодом такой же длины. Линия, столбцы, donut и помесячная heatmap. Выбранный часовой пояс используется для завершений, своевременности и дня начала сессии. Переносы задач агрегируются из entity_changes с кэшем по revision/timezone. Аналитика кэшируется в renderer.

Границы: сессия относится к дню начала, исторические интервалы паузы/смена суток не реконструируются; недельный score без зафиксированного плана исключает этот компонент. Дневной план отражает текущие даты задач. Проектный прогресс — текущее состояние, а не выдуманная историческая точка. Диапазон до 366 дней. Windows execution не выполнен. Запуск Windows из исходников: Node 22+, pnpm 10.20; install, `pnpm run rebuild`, `pnpm dev`. F в работе.
