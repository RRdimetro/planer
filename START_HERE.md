# Как начать в Codex

Открой каталог этого пакета как проект в Codex и отправь:

> Прочитай `CODEX_MASTER_SPEC.md` целиком и изучи `docs/reference/study_tracker_original.jpeg`. Реализуй FOCUS OS PRO строго по спецификации, начиная с M0, затем M1 и M2. Это должно быть локальное Windows-приложение Electron + React + TypeScript + SQLite в стиле Premium Forest, с 10 разделами. Не добавляй разделы «Привычки» и «Финансы». Делай функциональные вертикальные срезы, запускай тесты, записывай прогресс в IMPLEMENTATION_STATUS.md. Сначала выведи краткий план реализации и сразу приступай к M0; не останавливайся после генерации макетов. Для таблицы учёбы используй reference и точные начальные данные из §3.5. После этапа дай команды запуска для Windows PowerShell, результаты тестов и скриншоты реально работающего интерфейса.

В архиве находится эталонная фотография Excel. Код и приложение должны быть созданы Codex в этом каталоге.
