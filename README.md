# FOCUS OS PRO

Локальное настольное приложение на русском: Electron + React + TypeScript, SQLite/better-sqlite3 в main process, Drizzle repositories. Интерфейс Premium Forest. Ровно 10 разделов; разделов привычек и финансов нет.

**Это рабочая предварительная версия, а не завершённый релиз по всему MASTER SPEC.** Все разделы подключены к реальным данным, но расширенные требования реализованы частично. Точный перечень — [IMPLEMENTATION_STATUS.md](IMPLEMENTATION_STATUS.md).

## Windows 10/11 x64: запуск из исходников

Установите Node.js **22.18.0 или новее** (LTS 22 рекомендуется), затем откройте PowerShell в распакованном каталоге проекта:

```powershell
corepack enable
corepack prepare pnpm@10.20.0 --activate
pnpm install --frozen-lockfile
pnpm rebuild
pnpm dev
```

`pnpm rebuild` пересобирает нативный SQLite под Electron. Первый install требует сети; после установки приложение работает локально без обязательного сервера, регистрации и внешних API. Dev-сервер Vite нужен только разработчику; production загружается из локальных файлов.

Проверки и production build:

```powershell
pnpm typecheck
pnpm lint
pnpm test
pnpm build
pnpm test:e2e
node scripts/study-e2e.mjs
node scripts/modules-e2e.mjs
node scripts/backup-e2e.mjs
```

Тесты Vitest запускаются через Electron в режиме Node, чтобы использовать тот же ABI SQLite, что и приложение. Базы E2E создаются отдельно в системном temp, реальные данные не затрагиваются. В backup E2E системные диалоги подменяются тестовыми ответами; desktop IPC и ZIP/restore остаются настоящими.

## Windows installer

```powershell
pnpm dist:win
```

В `release/` должны появиться NSIS installer и portable `.exe`. Подготовлен `.github/workflows/windows.yml` с проверками и сборкой. Workflow **не запускался** в этой сессии. Здесь доступен Linux, поэтому Windows installer и Windows smoke test **не проверены и не поставляются**. Фиктивного `.exe` нет. Сборки без сертификата издателя могут вызывать предупреждение Windows SmartScreen.

## Данные и учебный импорт

Данные: `%APPDATA%\FOCUS OS PRO\focus.db`, режим WAL. Каталог открывается кнопкой в Настройках. Обновления не удаляют базу. При первом запуске выберите пустое пространство или добровольный импорт учебного референса. Импорт переносит все 9 предметов и 54 статуса этапов, не заменяет существующие предметы. Контрольные сущности тестов никогда не добавляются в пользовательскую базу.

Учебная отметка: клик → выполнено, повторный → не выполнено; Alt+клик или правая кнопка → неизвестно. Пустые экзамены/итоги остаются null. РК/ДЗ — независимые исходные агрегаты; подробные этапы не суммируются с ними.

Настройки → «Создать ZIP-копию» сохраняет manifest с SHA-256, SQLite, JSON-данные и журнал истории. Восстановление требует подтверждения, проверяет формат и хеши, применяется транзакционно. Перед восстановлением дополнительно сохраняется `before-restore.json` в каталоге данных. JSON импорт заменяет данные после подтверждения. Markdown-заметки экспортируются из раздела Заметки.

Горячие клавиши: Ctrl+K — поиск/команды, Ctrl+N — новая задача, Ctrl+Z — отмена доменного изменения вне текстовых полей. Виджеты можно переставлять перетаскиванием или кнопкой ↕; высоту менять нижним правым уголком, затем отпустить мышь — размер сохраняется.

## Диагностика

- `NODE_MODULE_VERSION` / SQLite binding: закройте приложение, выполните `pnpm rebuild`, затем повторите запуск. Не подменяйте Electron binding сборкой для системного Node.
- Ошибки IPC логируются в `errors.log`; ошибка открытия БД показывается системным диалогом, база не пересоздаётся автоматически.
- При сбое импорта текущая БД остаётся прежней. Для повреждённой базы сначала сохраните копию всего каталога данных и восстановите проверенный ZIP.
- Уведомления возможны при работающем приложении. При закрытии сессия фокуса при следующем запуске отмечается прерванной; паузу можно продолжить. Сон/длительные провалы таймера не начисляют время.
- На Linux для GUI требуется X11/Wayland. В этой среде тесты выполнялись на Xorg dummy `DISPLAY=:99`; `--no-sandbox` применяется только тестовыми launch-скриптами в изолированной CI-среде.
