# C — Workspaces

Проверено на Linux/Electron: 48 unit/integration, strict TypeScript, ESLint, production build. Electron E2E экспортирует настоящий XLSX через main bundle, импортирует ровно одну изменённую ячейку после предпросмотра, создаёт backup, расширяет группу и проверяет сохранение после перезапуска. Палитра создаёт проект, task/Gantt/Kanban/activity работают. 8 настоящих PNG: Projects/Study × demo/empty × 1366/1920.

Миграция v5 добавляет только явные привязки агрегатов к этапам. 9 исходных предметов, четыре группы, 54 статуса, неизвестные значения и null оценки сохранены. Без явной привязки исходные РК/ДЗ не пересчитываются. Существующие группы нельзя сократить с потерей ячеек.

XLSX принимает шаблон экспорта приложения, показывает изменения и создаёт копию до атомарного объединения. Формулы требуют предварительной вставки значений; произвольные структуры XLS и сопоставление колонок не реализованы. Пользовательские и demo-книги разделены. Gantt показывает только известные даты; прогноз появляется при достаточной истории.

Windows execution не выполнен. Следующие этапы D–F ещё в работе. Запуск на Windows: Node 22+, Corepack/pnpm 10.20, `pnpm install --frozen-lockfile`, `pnpm run rebuild`, `pnpm dev`. Для отдельной demo-базы: `pnpm preview:design -- --concept B` (см. README).
