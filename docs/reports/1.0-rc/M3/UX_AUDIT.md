# M3 — ежедневные сценарии

| Сценарий | Действия и результат | Ошибки/отмена |
|---|---|---|
| Новая задача | Ctrl+N → текст → Enter; один сохранённый ID | Валидация до записи; saving-state исключает повторное отправление |
| Завершение | Один клик checkbox | Toast с Undo только для текущей revision; Ctrl+Z остаётся |
| Недельный перенос | Drag/drop либо стрелки на ручке | Проверяется SQLite persistence; frozen snapshot не меняется |
| Учебный этап | Один клик по ячейке | Toast и Undo; unknown отдельно, без навязанного дополнительного диалога |
| Подходы | Редактор тренировки: checkbox/повторы/вес в одной форме | Закрытие изменённого workout требует подтверждения |
| Фокус выбранной задачи | Кнопка в существующей Task Drawer | Другая активная сессия не заменяется; pause/resume доступны |
| Аналитика | Смена периода и фильтров без перехода страницы | Неверный диапазон явно отклоняется, данные не меняются |
| Заметки | Автосохранение, очередь дренируется до навигации/close | Отдельный quiet status; нет всплывающего сообщения на каждую букву |
| Несохранённый редактор | Esc/close спрашивает о потере правок | «Остаться» сохраняет поля; Ctrl+N/K не заменяют открытый редактор |
| Ошибка записи | Реальный IPC отказ SQLITE_FULL в тестовой среде | Читаемая ошибка внутри диалога, форма остаётся, ложного success нет; retry сохраняет |
| Backup | Native Save dialog, actual ZIP/проверка | Success только после верификации; отмена диалога не объявляет создание |

Обнаружена ошибка доступности прежнего global alert: Radix скрывает фон от assistive technologies. Добавлен alert/live-region внутри активного диалога, sticky при прокрутке; системное описание ошибки очищается при успешном действии. Сохранение теперь ожидается формой, busy/dirty состояния явные. SQLite-технические названия убраны из обычного success сообщения.

Реальный Linux Electron E2E и unit/integration — отчёты рядом. Windows gate остаётся открытым. Скриншот настоящего отказа: M3/save-error.png. Используются только отдельные временные базы. Windows запуск из source: install → run rebuild → build → dev.
