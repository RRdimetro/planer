# M2 — Visual Polish

Сохранены Obsidian B, Forest Noir, навигация 64px, локальные шрифты, все 10 страниц и сохранённые пользовательские layouts. Новый default layout подчёркивает Daily Score, задачи и настоящий недельный график; сохранённые пользовательские порядки/размеры не перезаписываются. Вторичные показатели уменьшены. Контурная графика статична и деликатна.

Введены общие типографические токены 12/13/14/19/32px, поверхность/контроль/фокус, единые интервалы. Настроены календарь, task cards, roadmap/project cards, учебная таблица, fitness, BI-графики, редактор и настройки. Recharts учитывает OS reduced motion и настройку, длительность 220ms; drawer/modal/hover 160–220ms.

Проверено 60 основных PNG (demo/empty × 10 × 3 размера) и 20 реальных диалогов в Electron. Нет renderer errors/горизонтального переполнения. При аудите найдены и исправлены 8 случаев низкого контраста: завершённые события, «+ План», легенда и цифры heatmap. Повторный computed text contrast audit: 0 нарушений в обследованных текстовых узлах; градиенты и native Windows UI требуют визуального/платформенного контроля. Это не независимая WCAG-сертификация.

TypeScript, ESLint, production build и unit/integration выполнены; вывод рядом. Базы только временные. Windows 125% DPI не заявляется; M1 по-прежнему blocked. Запуск Windows: pnpm install --frozen-lockfile; pnpm run rebuild; pnpm build; pnpm dev.
