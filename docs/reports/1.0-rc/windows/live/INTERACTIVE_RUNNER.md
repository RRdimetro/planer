# Интерактивная Windows-приёмка RC1

Подключите Windows10/11 x64 через RRdimetro/planer → Settings → Actions → Runners → New self-hosted runner. Добавьте custom label `focus-interactive` наряду с self-hosted/Windows/X64. Используйте команды регистрации из GitHub локально; регистрационный token не отправляйте в чат. Запустите `run.cmd` в открытой пользовательской Windows-сессии, не как службу. Дождитесь Online/Idle.

Установите именно NSIS из папки Windows CI — 2026-11-05 на Drive. Сохраните копию рабочих данных до установки; тест открывает отдельную временную базу. Узнайте полный путь установленного FOCUS OS PRO.exe через свойства ярлыка. Сам тест не выбирает рабочую базу и не импортирует demo.

В Windows Settings → System → Display задайте системный масштаб100%, при необходимости выйдите/войдите и снова запустите runner. Разрешите уведомления FOCUS OS PRO, выключите режим «Не беспокоить» для проверки видимого toast. Не используйте Electron zoom или force-device-scale-factor.

На GitHub Actions выберите **Interactive Windows native acceptance** → Run workflow → ветку release/windows-rc1. Укажите scale=1, installed_exe=полный путь к установленному EXE. Остальные значения оставьте по умолчанию, finalize=false. Тест сверяет фактическую версию, scaleFactor, GetDpiForWindow, SQLite integrity и видимый OS toast. Сохраните полученный run ID.

Затем измените системный масштаб на125%, при необходимости снова войдите в систему и запустите runner. Повторите workflow с scale=1.25, finalize=false. Сохраните второй run ID.

Последний запуск: системный масштаб150%, scale=1.5, finalize=true. В evidence_100_run/evidence_125_run укажите ID двух успешных native-прогонов, core_run=41991402257. Workflow скачает исходные реальные install/upgrade/portable evidence и две native-проверки, затем выполнит неизменяемую проверку общего gate. Все три native отчёта должны относиться к одной версии и одному SHA256 установленного app.asar. Подменять версию/флаги отчётов нельзя. Артефакты с ошибками также сохраняются для диагностики.

Можно прислать «runner готов» и путь к установленному EXE: тогда workflow будет запущен из этой сессии. Путь не является паролем; токены и пароли не нужны. После смены системного масштаба сообщите о готовности следующего прогона.

Успешный RC gate подтверждает проверенный RC1. Для финальной версии1.0.0 потребуется сборка и проверка уже финального бинарника; старые отчёты другой версии не принимаются автоматически. До этого Stable не объявляется. Новых функций и изменений дизайна этот workflow не добавляет.
