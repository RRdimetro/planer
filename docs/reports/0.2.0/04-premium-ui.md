# Этап 4 — Premium Forest и изолированный preview
Главная: атмосферный banner до 130 px, шесть реальных KPI, график последних 7 дней, три приоритета, задачи и расписание, проекты/учёба, сохраняемые перестановка/высота виджетов. Проекты: плитки, взвешенный прогресс, roadmap/milestones, зависимости, привязанные Markdown-заметки и файлы, осторожный прогноз по ≥3 завершениям за 14 дней. Доработаны календарь, тренировки и индивидуальные стили остальных экранов.

Демо — отдельный процесс с отдельным userData/SQLite. Только явное действие в Настройках или FOCUS_DEMO=1 включает seed. Рабочая база не копируется и не заполняется демонстрацией. Во всех демо-экранах постоянная плашка. ZIP и JSON помечаются workspace; cross-mode import/restore запрещён. Seed не перезаписывает даже изменённую демонстрационную базу.

60 скриншотов настоящего Electron: user/demo × 10 страниц × 1366/1920/2560. Проверены renderer errors, page horizontal overflow, отсутствие демо-сущностей в пользовательской базе после демо/перезапуска. См. 04-design-e2e.json. User-скриншоты показывают только одобренный учебный импорт; demo-скриншоты явно помечены.

Добавлено подтверждение сброса pending autosave при закрытии окна: main не закрывает SQLite до завершения renderer flush. Regression E2E notes-flush проверяет немедленный переход и закрытие до debounce, после перезапуска текст точен. Гонка раннего закрытия при загрузке устранена handshake подписчика. Проекты/связанные заметки проверяются отдельным 04-projects-e2e.json.

Windows renderer smoke пока не выполнялся; визуальные проверки проведены на Linux Electron, а не на Windows.
