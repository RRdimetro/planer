# FOCUS OS PRO 1.0.0-rc.1

Статус: **Release Candidate, Windows acceptance blocked**. Продолжение 0.3.0 на отдельной ветке `release/1.0-rc-polish`, Electron 39.8.10 / React 19 / SQLite (better-sqlite3 12.11.1). Все десять разделов, appId, пользовательский каталог и схема v5 сохранены. Новых разделов и разрушительных миграций нет.

- Доводка утверждённого Obsidian Command Center B: главный Daily Score, реальные линии динамики, вторичные KPI меньшего веса, типографика, поверхности и индивидуальные экраны.
- Читаемые подписи и исправления найденных проблем контраста; reduced motion охватывает графики, портальные диалоги и пользовательскую настройку.
- Быстрые задачи с клавиатуры, фокус из задачи, защищённые dirty/busy формы, подтверждения после успешной записи. Ошибки записи видны внутри активного диалога, черновик остаётся для повторной попытки. Undo завершения сохранён.
- Home исключает перерывы из рабочего времени. Исправлены точные дедлайны и общий расчёт прогресса/прогноза проектов. Прогноз не использует дубликаты и будущие завершения.
- Устранены повторное создание Intl.DateTimeFormat и избыточная сортировка календаря; виртуализирован журнал фокуса. Замеры и ограничения производительности опубликованы, универсального ускорения всех страниц не заявляем.
- Проверены обновления SQLite fixtures из фактических версий 0.2.0 и 0.3.0, аварийный SIGKILL в WAL-транзакции, сохранность 9 предметов / 4 групп / 54 статусов и вложений.

66 unit/integration tests прошли на Linux Electron. Реальные GUI-регрессии, снимки и окончательная матрица находятся в `docs/reports/1.0-rc/`. Windows Setup/Portable являются настоящими unsigned EXE-кандидатами после кросс-сборки и статической проверки embedded payloads; они **не проверены запуском Windows**.

Репозиторий пользователя `RRdimetro/planer` подключён как origin, но авторизация Actions/push недоступна. Windows CI job URL отсутствует. Не выданы сертификаты установки, обновления, native DPI или системной доставки уведомлений. См. `KNOWN_ISSUES.md`.
