# Этап 3 — программы тренировок и фактический прогресс
SQL-связанные programs/program_exercises/exercises/workouts/workout_sets. Создание/изменение программ и упражнений, план подходов, повторы/веса, явная отметка факта каждого подхода, беговая дистанция/время/темп, недельный календарь, журнал. Удаление программы отвязывает её от старых тренировок, но не удаляет историю подходов.

Графики объёма и дистанции, персональные рекорды веса и повторов, оценка 1ПМ по Эпли только для ≤12 повторов. В расчёт объёма и рекордов попадают только отмеченные выполненными подходы завершённых тренировок. Применение программы заполняет план, не факт. Дни отдыха не штрафуются.

25 unit/integration проходили до финальной визуальной доработки, включая контроль 2×8×60=960 кг, пробег 5 км, оценку 1ПМ=76 кг, исключение плановых подходов, SQL rollback, сохранение при удалении программы и ZIP round-trip. Electron E2E прошёл через UI: библиотека → программа → тренировка → подходы → 960 кг → закрытие/повторное открытие. См. 03-fitness-e2e.json и 03-fitness.png.

Показатели являются журналом фактов, не медицинскими рекомендациями. При отсутствии записей графики пусты с полезными действиями. Windows не проверен на этом этапе; команды в README.
