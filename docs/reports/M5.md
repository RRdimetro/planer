# M5 — предварительная сборка, не завершённый Windows-релиз

Работают 10 экранов Premium Forest, поиск/команды Ctrl+K, Ctrl+N/Ctrl+Z, сворачивание панели, настройки, перемещение виджетов drag-and-drop/кнопкой и сохранение высоты. ZIP backup/restore с manifest, SHA-256, SQLite, JSON и историей; проверка доменных данных и транзакционный restore. Smart planner теперь применяет пакет одной транзакцией.

Валидация: typecheck/lint/build прошли, 13/13 unit/integration (включая повреждённый restore, неизменяемые исторические завершения, 1000 задач). Последний замер batch+read 1000 задач ~133 ms в текущем Linux worker, не Windows performance guarantee.

4 Electron E2E прошли на финальной сборке: M1 задачи, M2 учёба, M3 фокус/заметки, M5 ZIP backup→удаление→restore. Backup-тест подменяет только системные диалоги. 30 скриншотов 10 экранов в 1366/1920/2560, ни одного renderer error и horizontal page overflow. M0–M5.png — снимки соответствующих прогонов. Приложение упаковано в Linux directory build; отдельный smoke report — packaged-linux.json.

Windows: README содержит PowerShell quickstart и `pnpm dist:win`. CI .github/workflows/windows.yml подготовлен, но не запущен. В Linux нельзя подтвердить Windows native binding, установку/обновление/удаление NSIS, Windows notifications и SmartScreen. `.exe` не поставляется. Релиз M5 не принят.

Остаётся: вложения, повторы/occurrences, подзадачи/зависимости, расширенные фильтры/массовые действия, roadmap/milestones, resize календаря, структурированные силовые подходы/шаблоны, расширенные графики, CSV, полная настройка правил недели, распределение временных сессий по смене суток/DST. Tailwind установлен, UI реализован собственным CSS; часть рекомендуемых библиотек не используется в полном объёме. SQLite использует типизированные JSON records, а не всю нормализованную схему ТЗ.
