# M3
Тренировки: CRUD плана/факта, длительность, дистанция, вычисляемый темп, текст упражнений. Фокус: Pomodoro/свободный, выбор задачи, пауза/продолжение/завершение, запись в SQLite, прерванное состояние после закрытия, system notification. Заметки: Markdown editor/preview, autosave, теги, проект, экспорт .md через системный диалог; raw HTML/remote images выключены.

Проверки: 7/7 unit/integration. E2E таймера и заметки — M3-e2e.json. Скриншот M3.png. Windows: команды README (`pnpm install`, `pnpm rebuild`, `pnpm dev`), Windows smoke не выполнен.

Частично: силовые подходы сохраняются текстом, нет структурированных рекордов, шаблонов/графиков упражнений. Заметки без файловых вложений и связей с предметами/задачами. Это функциональный вертикальный срез, не вся спецификация M3.
