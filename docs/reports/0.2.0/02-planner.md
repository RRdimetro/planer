# Этап 2 — планировщик и структура задач
Подзадачи (SQL parent FK + запрет циклов), чек-листы, зависимости (SQL FK/триггер циклов и запрет преждевременного завершения), повторные отдельные occurrences с границами месяца/until, вложения до 25 МБ (BLOB, metadata, checksum, системные диалоги), массовое назначение даты/приоритета/недели/статуса и soft-delete с undo. Иерархический список, единые сохраняемые фильтры для трёх видов.

Календарь: день/неделя, единая временная прокрутка 06–24, месячная 42-клеточная сетка с понедельника, task/event/workout DnD, длительность pointer-resize и клавишами ↑/↓. События типов пара/дорога/личное/фокус; пользовательские ограничения дня/недели, рабочие дни, работа на лекциях, запрет сложных задач после тренировки. Ёмкость рассчитывается по объединению занятых интервалов, без двойного вычитания пересечений. Пересечения учитывают полночь. Smart preview учитывает приоритет/дедлайн/зависимости/слоты; atomic apply проверяет revision, пересечения, правила и ёмкость заново. Первоначальные планы хранятся отдельно и не меняются при переносах.

Additive migration v3: архив байтов вложений для undo + FK digests, SQL-триггеры циклов, перенос существующей истории в связанные entity_changes. Preflight на копии применяется ко всем версиям. Формат архивов v3 читает также ZIP v1.

GUI E2E пройден: checklist → attachment → subtask → event keyboard-resize → event DnD → 42-day month → preview (до применения БД не меняется) → atomic apply → frozen snapshot → restart с сохранёнными отношениями/байтами. JSON: 02-planner-e2e.json, PNG: 02-planner-week/month.png. Регрессии M1 и M2 прошли. Unit suite включает migration, cycle/rollback, recurrence, availability/deadlines и stale preview tests.

Ограничение: повтор следующей задачи создаётся при завершении текущего выполнения, не разворачивает бесконечную серию в календаре. Тип события «Пара» требует ручного заполнения. Fitness-схема и UI добавлены в этом изменении, их отдельная проверка фиксируется этапом 3.
Windows: README quickstart; Windows не проверен на этом этапе.
