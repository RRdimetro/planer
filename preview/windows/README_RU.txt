FOCUS OS PRO — Forest Noir V4 / три концепции главной

1. Распакуйте весь Windows_Preview_UNTESTED.zip в одну папку.
2. Запустите A_Editorial_Forest.cmd, B_Obsidian_Command_Center.cmd
   или C_Atmospheric_Bento.cmd. Это три независимые демо-базы.
3. Для пустого состояния используйте A_Empty.cmd / B_Empty.cmd / C_Empty.cmd.
4. Изменения в демо сохраняются между запусками. Рабочие данные не импортируются.

Каталоги находятся в %APPDATA%:
FOCUS OS PRO Forest Noir V4 A
FOCUS OS PRO Forest Noir V4 B
FOCUS OS PRO Forest Noir V4 C
Для пустых состояний к имени добавляется Empty.

Ctrl+K — поиск и команды. Стрелки/Enter — выбор. Escape — закрыть панель.
Ctrl+N — новая задача. Кнопка рядом с датой отключает пейзаж.

ВАЖНО: exe получен cross-build на Linux, не подписан и НЕ проверен
на Windows. Наличие exe не подтверждает установку, совместимость,
Windows DPI или обновление без потери данных. Это preview для выбора дизайна.
Полный отчёт, скриншоты и исходники находятся в соседнем Source.zip.

Прямой запуск exe открывает классический рабочий режим 0.2.0.
Для выбора дизайна запускайте указанные CMD-файлы.
